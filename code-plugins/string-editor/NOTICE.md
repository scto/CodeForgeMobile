# String-Editor – Herkunft

Portiert nach Kotlin/Jetpack Compose aus **StringEditor** von raredeveloperofc
(https://github.com/msmt2018/StringEditor, ursprünglich github.com/raredeveloperofc/StringEditor),
lizenziert unter der GNU General Public License v3.0 – wie CodeForgeMobile.

Übernommen: Listen- und XML-Ansicht von `strings.xml`, Neu/Bearbeiten/Löschen/Verschieben, Namensprüfung.
Neu: Seitenleiste mit allen String-Dateien des Projekts, verlustfreies Lesen und Schreiben (Kommentare, Arrays,
Plurals, Formatierung bleiben), Android-Maskierung, Suche, Sortieren, Kopieren als `@string`/`R.string`,
`translatable`, Sprachwechsel und fehlende Übersetzungen.
