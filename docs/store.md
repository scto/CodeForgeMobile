# Store

Plugins, Themes, Sprachpakete und Werkzeuge für CodeForge Mobile. Installation in der App unter **Einstellungen → Store**;
hier kannst du den Katalog nach Kategorien und Tags durchsuchen, sortieren (Relevanz, Downloads, Bewertung, Name,
aktualisiert, neu) und Pakete mit Prüfsumme herunterladen. Code-Plugins gibt es nur als Download (Sideload).

Bewertungen laufen über GitHub (ein Formular je Paket, Knopf „Bewerten“ auf der Paketseite); Downloads zählt das
Release des Store-Repos. Die Statistik wird täglich kurz nach Mitternacht und nach jeder Bewertung neu berechnet.
