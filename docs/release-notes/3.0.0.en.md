# CodeForge Mobile 3.0.0

An Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** This release is signed with the Android debug key and has not been systematically tested on devices yet (checklist: `docs/device-test-checklist.md`). Please report problems as an issue.

## Highlights

- **Its own Linux environment, no root** – a real shell in the Termux prefix (`/data/data/com.codeforge.app/files/usr`) instead of a rootfs/PRoot. `codeforge-env` handles the setup (JDK 17/21/25, Android SDK, NDK, CMake, Gradle, Kotlin, Git …).
- **Code editor** (Sora Editor): TextMate + Tree-sitter, minimap, sticky scroll, rainbow brackets, magnifier, pinch zoom, image preview, search & replace.
- **Language servers**: Kotlin, Java, XML and more through the extension manager, with an info dialog (state, runtime, diagnostics) and automatically installed dependencies.
- **Git panel** (JGit): diff, merge, commit, push/pull, graph, stash, tags, rebase, cherry-pick, reset, blame, hunk staging, conflict editor.
- **Build & Gradle**: build panel with problems view, **Gradle sync** and a filterable task picker, install/launch the APK, APK analysis and comparison.
- **Compose preview** with an on-device Kotlin compiler.
- **Layout designer** for Android layout XML (drag & drop, preview, properties, undo/redo) and an XML→Compose converter.
- **Asset Studio** (new): adaptive icons and drawables from images, XML vectors or the Material icon browser (≈2,080 icons, searchable).
- **Project wizard** with 9 templates (Gradle 9.6 / AGP 9.5 / Kotlin 2.3), submodule maker, dependency updater.
- **Signing manager**: create, import and export keystores, sign APKs.
- **AI assistant** (OpenAI, Anthropic, Gemini) with automatic provider detection from the key.
- **Material 3 Expressive**, adaptive layouts (phone/tablet/foldable), edge-to-edge, German and English.

## New since the first 3.0.0 build

**Editor**
- Kotlin: *Organize imports* and *Remove unused imports* (sorted, no duplicates, runs instantly, leaves files without a `package` line untouched).
- Annotation completion (`@Preview`, `@Composable`, Hilt, Room, JUnit …) with automatic import – even before the language server has started.
- Hover documentation with signature, parameters (including defaults), return type, package and `val`/`var`, in the colors of the editor theme.
- Matching brackets are clearly highlighted.

**Terminal & IDE**
- CodeForgeMobile greeting instead of the Termux MOTD; new commands `codeforge-env update | upgrade | search | remove`.
- Notification for builds, Git clones, SDK installations and open terminals – with *acquire/release wakelock*, *Exit* and the terminal count.
- The SDK manager lists build-tools and platform-tools from the mirrored releases `v36.1.0` and `android-sdk-37.0.0`.
- Import a project by opening it locally (no copy); all folders in `CodeForgeMobileProjects` show up automatically on the start screen.

**Fixes**
- Start screen: single-column project list; paths and metadata are no longer cut off.
- Gemini: current default model, key sent in the header, meaningful error messages; provider chips wrap.

**Build/Release**
- `:app` has a release block (R8 minify, resource shrinking, signing via `keystore.properties`/environment variables); R8 rule files for all Android modules. *`minifyReleaseWithR8` completes; the behavior of the release APK on devices has not been verified yet.*
- GitHub workflow **Build Debug APK** (artifact including SHA-256).

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
