# CodeForge Mobile 3.0.2

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.0.1

### Changed

- **Release-Automatik:** Workflow `bump-version.yml`: Auswahl `build` (`none` | `debug` | `release`) startet nach dem Bump den Debug- bzw. den signierten Release-Build (inkl. Schalter `prerelease`); Berechtigung `actions: write` ergänzt, damit `gh workflow run` funktioniert.
- **Release-Automatik:** `scripts/release/bump_version.py` ändert keine Dateien unter `.github/workflows/` mehr (der `GITHUB_TOKEN` darf sie nicht pushen).

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
