# CodeForge Mobile 3.0.1

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

This update (3.0.0 → 3.0.1, 51 commits) brings a debugger that actually works, much broader language support in the editor, a dedicated screen for AI providers and numerous fixes around language servers and package installation. The project is also dedicated to **Basti**. 🐕

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Highlights

- **JVM debugging works**: bundled DAP adapter on JDI, dialog for *launch program* or *attach to JDWP port*.
- **35 new TextMate grammars** (Python, JS/TS, C/C++, Go, Rust, SQL, Markdown, LaTeX …) plus keyword and dictionary completion.
- **AI providers screen** (*Settings → AI providers*): key, model and base URL per provider, connection test, live model list.
- **Seven new LSP plugins** (XML, C/C++, Bash, YAML, TOML, Python, kmp-lsp) on the new plugin model.
- **Gradle task list** when opening a project, searchable and grouped.
- **Dedication to Basti**: animated pixel figure, *About Basti* screen, a page of its own on the website.

## New

**Editor**
- 35 additional TextMate grammars incl. language configs (Dart, Python, JS/TS/TSX/JSX, C/C++, C#, Go, Rust, PHP, HTML, CSS, YAML, TOML, shell, Groovy/Gradle, SQL, Markdown, LaTeX, Lua, Smali and more).
- Per-language keyword suggestions and an English dictionary for text, Markdown and LaTeX as auto-completion.
- The LSP client supports `textDocument/foldingRange` and `textDocument/inlayHint` (groundwork for code folding and inline hints).

**Debugger**
- JVM debugging with a bundled DAP adapter on JDI; new dialog for *launch program* or *attach*. Tested on host JDK 21 (breakpoint, variables, evaluate, step) – not yet on a device.

**AI**
- New screen *Settings → AI providers*: encrypted API keys, model and base URL per provider, connection test, “Load models”.
- Model lists updated (Gemini per ai.google.dev, default `gemini-3.6-flash`; Anthropic and OpenAI extended).

**Build**
- Opening a Gradle project reads `tasks --all` once per session; the task dialog is searchable and shows icons and groups.

**Language servers & plugins**
- LSP diagnostic logging (`CF-LSP`): start command, stderr, exit code and runtime; on failure the last 40 stderr lines are shown.
- Example plugins migrated to the new plugin model (manifest v2, `lspServers`); new: XML (LemMinX), C/C++ (clangd), Bash, YAML, TOML (Taplo), Python (Pyright) and `kmp-lsp-plugin` 2.1.0 (prebuilt Termux binary, SHA-256 check).
- Developer guide *Developing plugins – from A to Z* with runnable examples in `examples/guide/`; plugin model comparison in `docs/plugin-modelle-vergleich.md`.

**About**
- About screen in a card layout (version with build number and type, links, licenses); the welcome screen shows the real app version.
- **Dedication to Basti**: pixel figure (adult and puppy), screen *Settings → About Basti*, a `/basti/` page and the figure in the website header.

**Website & documentation**
- Central site `scto.github.io/CodeForgeMobile` with Start, Store, APT repo, documentation and API reference in one menu.
- User guide (DE), user guide (EN), developer guide, APK documentation and module graph as a MkDocs site; KDoc for the whole public API, API reference with Dokka 2.
- **Release Debug APK** workflow (tagged pre-release) and `scripts/release/bump_version.py` to bump the version and generate release notes automatically.

## Fixes

- **Crash** “IOException: Stream closed” while typing when the language server process had already exited.
- **Completion popup** is no longer hidden by the keyboard.
- **Color preview** no longer jumps around on scroll, zoom and wrap.
- **Package installation**: dependencies are installed via `codeforge-env pkg` (instead of `apt-get`, exit code 134); large packages such as `libllvm` go before `clang`, so `codeforge-env pkg clang` completes.
- **Store**: language server entries show plugin and server state separately; missing servers can be installed afterwards.
- **Release build**: R8 failed on `Process.descendants()` (Java 9); the check now uses only APIs available on Android.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
