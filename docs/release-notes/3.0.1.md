# CodeForge Mobile 3.0.1

Android-Entwicklungsumgebung auf dem Handy: Editor, Terminal, Git, Gradle-Build, Language Server, Layout-Designer und Asset Studio – alles in einer App.

Dieses Update (3.0.0 → 3.0.1, 51 Commits) bringt einen Debugger, der wirklich funktioniert, deutlich mehr Sprachunterstützung im Editor, einen eigenen Bildschirm für KI-Anbieter und zahlreiche Fixes rund um Language Server und Paketinstallation. Das Projekt ist außerdem **Basti** gewidmet. 🐕

> ⚠️ **Vorabversion / Debug-APK.** Das Release ist mit dem Android-Debug-Schlüssel signiert und noch nicht systematisch auf Geräten getestet (Checkliste: `docs/device-test-checklist.md`). Bitte Fehler als Issue melden.

## Highlights

- **JVM-Debugging funktioniert**: mitgelieferter DAP-Adapter auf JDI, Dialog für *Programm starten* oder *an JDWP-Port anhängen*.
- **35 neue TextMate-Grammatiken** (Python, JS/TS, C/C++, Go, Rust, SQL, Markdown, LaTeX …) plus Schlüsselwort- und Wörterbuch-Vervollständigung.
- **KI-Anbieter-Bildschirm** (*Einstellungen → KI-Anbieter*): Schlüssel, Modell und Basis-URL je Anbieter, Verbindungstest, Live-Modellliste.
- **Sieben neue LSP-Plugins** (XML, C/C++, Bash, YAML, TOML, Python, kmp-lsp) auf dem neuen Plugin-Modell.
- **Gradle-Task-Liste** beim Öffnen eines Projekts, durchsuchbar und gruppiert.
- **Widmung an Basti**: animierte Pixelfigur, Bildschirm *Über Basti*, eigene Seite auf der Webseite.

## Neu

**Editor**
- 35 zusätzliche TextMate-Grammatiken inkl. Language-Configs (Dart, Python, JS/TS/TSX/JSX, C/C++, C#, Go, Rust, PHP, HTML, CSS, YAML, TOML, Shell, Groovy/Gradle, SQL, Markdown, LaTeX, Lua, Smali u. a.).
- Schlüsselwort-Vorschläge je Sprache und englisches Wörterbuch für Text, Markdown und LaTeX als Auto-Vervollständigung.
- LSP-Client unterstützt `textDocument/foldingRange` und `textDocument/inlayHint` (Grundlage für Code Folding und Inline-Hinweise).

**Debugger**
- JVM-Debugging mit mitgeliefertem DAP-Adapter auf JDI; neuer Dialog für *Programm starten* oder *anhängen*. Getestet auf dem Host-JDK 21 (Breakpoint, Variablen, Evaluate, Step) – auf dem Gerät noch nicht.

**KI**
- Neuer Bildschirm *Einstellungen → KI-Anbieter*: verschlüsselte API-Schlüssel, Modell und Basis-URL je Anbieter, Verbindungstest, „Modelle laden“.
- Modelllisten aktualisiert (Gemini nach ai.google.dev, Standard `gemini-3.6-flash`; Anthropic und OpenAI erweitert).

**Build**
- Beim Öffnen eines Gradle-Projekts wird einmal je Sitzung `tasks --all` gelesen; der Task-Dialog ist durchsuchbar und zeigt Symbole und Gruppen.

**Language Server & Plugins**
- LSP-Diagnose-Logging (`CF-LSP`): Startkommando, stderr, Exit-Code und Laufzeit; bei Fehlern erscheinen die letzten 40 stderr-Zeilen.
- Beispiel-Plugins auf das neue Plugin-Modell migriert (Manifest v2, `lspServers`); neu: XML (LemMinX), C/C++ (clangd), Bash, YAML, TOML (Taplo), Python (Pyright) und `kmp-lsp-plugin` 2.1.0 (fertiges Termux-Binary, SHA-256-Prüfung).
- Entwicklerhandbuch *Plugins entwickeln – von A bis Z* mit lauffähigen Beispielen unter `examples/guide/`; Vergleich der Plugin-Modelle in `docs/plugin-modelle-vergleich.md`.

**Über die App**
- Über-Bildschirm im Karten-Layout (Version mit Build-Nummer und Art, Links, Lizenzen); der Willkommensbildschirm zeigt die echte App-Version.
- **Widmung an Basti**: Pixelfigur (erwachsen und Welpe), Bildschirm *Einstellungen → Über Basti*, Seite `/basti/` und Figur in der Kopfzeile der Webseite.

**Webseite & Dokumentation**
- Zentrale Seite `scto.github.io/CodeForgeMobile` mit Start, Store, APT-Repo, Dokumentation und API-Referenz in einem Menü.
- Anwenderhandbuch, User Guide, Entwicklerhandbuch, APK-Dokumentation und Modulgraph als MkDocs-Seite; KDoc für die gesamte öffentliche API, API-Referenz mit Dokka 2.
- Workflow **Release Debug APK** (getaggtes Pre-release) und Skript `scripts/release/bump_version.py` zum automatischen Hochzählen von Version und Release Notes.

## Fixes

- **Absturz** „IOException: Stream closed“ beim Tippen, wenn der Language-Server-Prozess schon beendet war.
- **Completion-Fenster** wird nicht mehr von der Tastatur verdeckt.
- **Farbvorschau** springt beim Scrollen, Zoomen und Umbrechen nicht mehr herum.
- **Paketinstallation**: Abhängigkeiten werden über `codeforge-env pkg` installiert (statt `apt-get`, Exit-Code 134); große Pakete wie `libllvm` kommen vor `clang`, sodass `codeforge-env pkg clang` durchläuft.
- **Store**: Sprachserver-Einträge zeigen Plugin- und Server-Zustand getrennt; fehlende Server lassen sich nachinstallieren.
- **Release-Build**: R8 brach an `Process.descendants()` (Java 9) ab; die Prüfung nutzt jetzt nur auf Android verfügbare APIs.

## Installation

1. APK `app-debug.apk` herunterladen und Prüfsumme mit `SHA256SUMS.txt` vergleichen.
2. Installieren (Installation aus unbekannten Quellen erlauben).
3. Beim ersten Start dem Onboarding folgen: Berechtigungen erteilen, Bootstrap installieren, Setup mit `codeforge-env` ausführen.

Unterstützte Architekturen: **aarch64** (Hauptziel) und **arm**.

## Bekannte Einschränkungen

- **Code Folding** fehlt (Sora-Editor 0.23.4 kann eingeklappte Bereiche nicht darstellen).
- `targetSdk = 28` ist nötig, damit Termux-Binaries ausführbar sind – **kein Play-Store-Release möglich**; Verteilung über GitHub/F-Droid/Sideload.
- Das Android-SDK 37 (`android-sdk-37.0.0`) steht nur für aarch64 zur Verfügung.
- Gerätetests (Bootstrap, W^X, Layouts, LSP) sind noch offen.
