# CodeForge Mobile 3.0.5

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.0.4

### New

- **KI-Agent, Grundlage:** Neues Modul `:libs:agent`: provider-neutrale Agentenschleife (`AgentLoop`, `Flow<AgentEvent>`) mit Werkzeugen (`read_file`, `list_dir`, `search_text`, `create_file`, `edit_file`, `delete_path`, `get_diagnostics`, `todo_write`), Berechtigungsmodi (Nachfragen / …
- **KI-Agent, Grundlage:** `:libs:ai-client`: `OpenAiAgentClient` (Chat Completions, `max_completion_tokens` nur gegen api.openai.com) und `GeminiAgentClient` (Funktionsaufrufe; `thoughtSignature` von Gemini 3 wird in der Aufruf-ID mitgeführt) auf gemeinsamer SSE-Transportschicht, je …
- **KI-Agent, Grundlage:** `:libs:ai-client`: `AnthropicAgentClient` (Streaming-Werkzeugaufrufe der Anthropic-Messages-API, Retry bei 429/5xx) plus testbare `AnthropicAgentWire` (Request-Body, SSE-Zusammensetzung inkl. `input_json_delta`).
- **KI-Agent, Projektkontext:** Der Agent lädt Projektregeln aus `AGENTS.md`, `CLAUDE.md` oder `.codeforge/AGENT.md` (max. 8000 Zeichen) in den System-Prompt.
- **KI-Agent, Projektkontext:** Skills: `.codeforge/skills/<name>/SKILL.md` und `.claude/skills/<name>/SKILL.md` (Frontmatter `name`/`description`).
- **KI-Agent, Editor:** Editor-Schnellaktion „Im Agenten fragen“: Auswahl (oder ganze Datei) wird als Anhang-Chip an die nächste Agent-Nachricht gehängt, das Agent-Panel öffnet sich automatisch.
- **KI-Agent, MCP:** `:libs:mcp`: MCP-Client (Streamable HTTP, Legacy-SSE mit Fallback, stdio über Termux), `.mcp.json`/`mcpServers`-Format kompatibel mit Claude Code und Cursor.
- **KI-Agent, MCP:** Agent-Panel: Verbindungsdialog zum Hinzufügen, Aktivieren, Entfernen und Freigeben von MCP-Servern.
- **KI-Agent, App:** Neues Modul `:feature:agent` und Drawer-Bereich „Agent“: Chat-Panel mit Werkzeugstatus, Aufgabenliste, Berechtigungsmodus (Fragen / Auto / Plan), Freigabe-Karte für schreibende Aktionen und „Änderungen zurücknehmen“ pro Zug.
- **KI-Agent, App:** `FileAgentWorkspace` (`:libs:agent`): Dateizugriff nur innerhalb des Projekts (Pfad- und Symlink-Schutz, atomares Schreiben, Größenlimit, Suche ohne Build-Ordner/Binärdateien).
- **KI-Agent, App:** Werkzeug `run_gradle` (Art „Ausführen“, braucht im Modus „Fragen“ Freigabe): führt Gradle-Tasks über die vorhandene Build-Anbindung aus und liefert Erfolg bzw. die Compilerfehler mit Datei und Zeile zurück; Task-Argumente werden gegen Shell-Zeichen geprüft, …
- **KI-Agent, App:** Diff-Vorschau: Die Freigabe-Karte zeigt bei `create_file`/`edit_file` den Unified-Diff der geplanten Änderung (`TextDiff`, `AgentTool.preview`), die Änderungskarte klappbare Diffs je Datei.
- **KI-Agent, App:** Der Chat-Verlauf wird je Projekt gespeichert (`AgentHistoryStore`, alte Werkzeugergebnisse gekürzt) und beim Öffnen wiederhergestellt; „Neuer Chat“ löscht ihn.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
