# CodeForge Mobile 3.5.0

Android-Entwicklungsumgebung auf dem Handy: Editor, Terminal, Git, Gradle-Build, Language Server, Layout-Designer und Asset Studio – alles in einer App.

> ⚠️ **Vorabversion / Debug-APK.** Das Release ist mit dem Android-Debug-Schlüssel signiert und noch nicht systematisch auf Geräten getestet (Checkliste: `docs/device-test-checklist.md`). Bitte Fehler als Issue melden.

## Änderungen seit 3.4.0

### Neu

- **KI-Agent: IDE-Werkzeuge** (nach dem Vorbild von CodeAssist): Sprachserver (`find_symbol`, `go_to_definition`, `find_references`, `rename_symbol`, `list_quick_fixes`/`apply_quick_fix`, `organize_imports`, `format_file`), Projekt (`project_overview`, …
- **KI-Agent: Ersatzschlüssel und Anfragelimit** je Anbieter (Einstellungen → KI): Schlüsselwechsel bei 429, erschöpftem Kontingent oder abgelehntem Schlüssel; Takten der Anfragen pro Minute (konfiguriert oder aus 429 gelernt).
- **MCP:** Anmeldung bei MCP-Servern über den Browser (OAuth 2.1 nach MCP-Spezifikation, Tokens werden erneuert); CodeForge selbst als MCP-Server auf `127.0.0.1:8765` mit Token, gleiche Freigaben wie im Agenten. / MCP OAuth sign-in and CodeForge as MCP server.
- **PT-Werkzeug „AGP-9-Migration“** (`com.codeforge.plugin.agp9-migrate.tool`): stellt Projekte auf Android Gradle Plugin 9.0 um – AGP/Gradle 9.1/Kotlin 2.2.10, eingebautes Kotlin (kotlin-android entfernen, `kotlinOptions` → `kotlin.compilerOptions`), kapt → …

### Geändert

- **Debugger als Plugin:** Haltepunkte, Haltepunkt-Übersicht und Debug-Leiste sind standardmäßig ausgeblendet und erscheinen erst mit dem Plugin „Debugger“ (`com.codeforge.plugin.debugger.feature`, Store → Code-Tools → Debugger).

### Fixes

- Code-Faltung: Tippen auf die Faltmarken ging an die Haltepunkt-Fläche verloren.
- Lupe: nutzt jetzt die System-Lupe von Android (API 28+) statt der PixelCopy-Lupe von sora-editor, die in der Compose-Oberfläche nicht erschien. / Magnifier now uses the Android system magnifier.
- Zeilennummern anheften: Die Einstellung erklärt jetzt, dass sie nur ohne Zeilenumbruch wirkt (mit Umbruch gibt es kein seitliches Scrollen). / Pin line numbers explains that it needs word wrap off.

## Installation

1. APK `app-debug.apk` herunterladen und Prüfsumme mit `SHA256SUMS.txt` vergleichen.
2. Installieren (Installation aus unbekannten Quellen erlauben).
3. Beim ersten Start dem Onboarding folgen: Berechtigungen erteilen, Bootstrap installieren, Setup mit `codeforge-env` ausführen.

Unterstützte Architekturen: **aarch64** (Hauptziel) und **arm**.

## Bekannte Einschränkungen

- `targetSdk = 28` ist nötig, damit Termux-Binaries ausführbar sind – **kein Play-Store-Release möglich**; Verteilung über GitHub/F-Droid/Sideload.
- Das Android-SDK 37 (`android-sdk-37.0.0`) steht nur für aarch64 zur Verfügung.
- Gerätetests (Bootstrap, W^X, Layouts, LSP, Code-Faltung, Terminal-Farbschemata) sind noch offen.
