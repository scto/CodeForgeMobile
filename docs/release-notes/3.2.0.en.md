# CodeForge Mobile 3.2.0

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.1.5

### New

- **Plugins, API 4:** **Plugin-API 4:** Projekt-Dienst (Module, Build-Ergebnisse des letzten Gradle-Builds), Build-Dienst (Gradle-Aufgaben ausführen, nur Aufgabennamen), Dienste zwischen Plugins (`services()`), Vorschauen je Dateityp (`PluginPreview`, wie `customEditors` in VS …
- **Plugins, API 4:** **Signaturen und Herkunft:** Plugins können signiert sein (EC P-256, `scripts/plugin-sign.py`); Updates müssen denselben Schlüssel tragen.
- **Plugins, API 4:** **Sieben Code-Plugins** (`code-plugins/`, Sideload): Markdown-Vorschau, Daten-Betrachter (CSV/TSV/JSON), SQLite-Betrachter, Projekt-Skripte (npm/pnpm/yarn/bun, Make, Cargo, Go, just), REST-Client (`.http`), Gradle-Aufgaben, Python-Tests (pytest).
- **Plugins, API 4:** **Acht Sprachpakete** als Bundles (Python, Rust, Go, Web, C/C++, Shell, Konfiguration, Kotlin/Java).
- **Plugins, API 4:** **VS-Code-Konverter:** übernimmt Farbschemata, Icon-Themes, Grammatiken samt Dateiendungen, Snippets und Extension-Packs; lädt direkt von Open VSX (`openvsx:<publisher>.<name>`) und schreibt einen Bericht über nicht Übertragbares.
- **Plugins, API 4:** **Store:** Kategorienbaum, Tags, Suche, sechs Sortierungen, Bewertungen (GitHub-Formular) und Downloads (Release des Store-Repos), täglich aktualisiert; Detailansicht mit Rezensionen und „Bewerten“ in App und Website; Spiegel-Download als Rückfall.
- **Plugins, API 4:** Doku: Leitfaden (API 4, Code-Plugins, VS Code → CodeForge), Plugin-Liste, Plugin-Signaturen.
- **Compose-Vorschau:** **Gradle-Build-Ergebnisse nutzen:** Liegt ein aktueller Gradle-Build des Projekts vor (keine Quell- oder Ressourcendatei neuer als der Build; AGP 8 und 9, Android- und reine Kotlin/JVM-Module), kompiliert die Vorschau nur noch die geöffnete Datei gegen die …
- **Compose-Vorschau:** **Echte Ressourcen:** Mit Gradle-Build lädt die Vorschau die gelinkten Ressourcen (`*.ap_`) – Bilder (`painterResource`), Fonts, Texte, Farben und Dimensionen kommen aus dem Projekt statt aus Platzhaltern.
- **Compose-Vorschau:** Hinweis unter der Vorschau: „Klassen und Ressourcen aus dem letzten Gradle-Build“.

### Fixes

- Sprachpakete der Oberfläche: Übersetzungen nach Schlüssel statt Position zugeordnet (neue Texte verschoben alle folgenden; das Veröffentlichen des Stores brach ab).

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
