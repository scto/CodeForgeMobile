# CodeForge Mobile 3.0.7

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.0.6

### New

- Editor: Schalter „ICU-Bibliothek für die Wortauswahl“ (Standard an) – Doppeltippen und langes Drücken bestimmen Wortgrenzen über `android.icu.text.BreakIterator` (`props.useICULibToSelectWords`), korrekt auch bei CJK/Thai, Zahlen und Emojis; ohne …
- Editor: „Schriftart-Ligaturen“, „Soft-Tab benutzen“ (Leerzeichen statt `\t`, für TextMate, Tree-sitter und Klartext über die Hülle `TabPolicyLanguage`), „Leere Zeilen mit Backspace löschen“, „Tab mit Backspace löschen“ – alle standardmäßig an.
- Build: `tasks --all` in der Task-Auswahl (Gruppe „Help“, auch vor dem ersten Sync); aktualisiert zugleich die Task-Liste.

### Changed

- Editor: Texte für Lupe, Zeilenumbruch, Sticky Scroll und „Zeilennummern anheften“ überarbeitet.

### Fixes

- Compose-Vorschau in Release-Builds: `feature/composepreview/consumer-rules.pro` behält Compose (runtime, ui, foundation, animation, material3, ripple), Standard-Symbole, `androidx.lifecycle`, `androidx.activity.compose`, `kotlin` und `kotlinx.coroutines` …
- Vorschau-Fehler landen mit Stacktrace im App-Log (Tag `ComposePreview`); doppelte Hilt-Bindung von `CfmLogger` (`core:data`) entfernt.
- kmp-lsp (Plugin 1.0.1): JVM-Optionen in Einstellungen → Sprachserver; sie gelten für den Java-Helfer `kmp-jar-indexer.jar` (über `JDK_JAVA_OPTIONS`).
- „String-Ressource extrahieren“: gleicher Schlüssel mit anderem Text → `_2`, `_3` …; einzelne kleingeschriebene Wörter (`"crash"`) werden nicht mehr vorgeschlagen; `getSystemService`, SQL-Aufrufen, `getProperty`/`getenv` u. a. gelten als technisch;
- Test `testRunRequestBridgeTriggersTestsTabAndExecution` wartet auf den Tab-Wechsel statt fester 250 ms.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
