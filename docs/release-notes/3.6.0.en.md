# CodeForge Mobile 3.6.0

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.5.2

### Changed

- **Befehlspalette aufgeteilt** in `:libs:command-palette-api` (Verträge) und `:libs:command-palette-impl` (ein Anbieter je Bereich, Filter, Hilt).
- **Gefilterte Testläufe griffen nie:** Gradle-Aufrufe wurden stur an Leerzeichen zerlegt, `--tests "Klasse"` kam mit Anführungszeichen bei Gradle an.
- **OpenRouter-Anmeldung: „Unable to resolve host openrouter.ai“ behoben.** Die Rückleitung erreichte die App, während sie noch hinter dem Browser im Hintergrund lag; Android sperrt Hintergrund-Apps das Netz, der Schlüsseltausch schlug sofort fehl.
- **SDK-Manager öffnet sofort:** zuletzt geladene Paketliste wird sofort gezeigt und im Hintergrund aktualisiert, 5 Minuten im Speicher wiederverwendet (nach Installation/Deinstallation neu); das Skript speichert auch das entfernte Manifest 6 Stunden zwischen, …
- **PT-Werkzeug „AGP-9-Migration“ nach Googles Skill `agp-9-upgrade` ergänzt:** hebt KSP (2.3.6) und Hilt (2.59.2) an, stellt `kapt(…)` für KSP-fähige Prozessoren auf `ksp(…)` um (sonst `legacy-kapt`), ergänzt `buildFeatures.buildConfig`, entfernt …

### Fixes

- **„Mit OpenRouter anmelden“ blieb auf einer `localhost`-Adresse hängen:** Der Rückleitungs-Empfänger wurde von leeren Vorab-Verbindungen des Browsers (Preconnect) blockiert; jetzt wird jede Verbindung parallel mit Zeitlimit bedient.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP, code folding, terminal color schemes) are still open.
