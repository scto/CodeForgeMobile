# CodeForge Mobile 3.0.4

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.0.3

### Fixes

- **Release-Build / Editor:** TextMate-Highlighting fiel in der R8-Release-APK auf Klartext zurück („Abstract classes can't be instantiated … Class name: de.b“, „Language with … scope name not found“): sora-editor liest `languages.json` per Gson-Reflection, R8 hatte die Klassen umbenannt.
- **SDK / Compose-Vorschau:** Mehrere Platforms gleichzeitig installieren (Mehrfachauswahl im SDK-Manager) startete parallele `sdkmanager`-Läufe im selben SDK-Verzeichnis; es blieben Platform-Ordner ohne `android.jar` zurück und die Compose-Vorschau meldete „Android-Plattform fehlt“.
- **SDK / Compose-Vorschau:** Compose-Vorschau nimmt die neueste Platform, die eine lesbare `android.jar` hat, statt nur die neueste installierte.
- **SDK / Compose-Vorschau:** `codeforge-env`: **eine** Installationssperre für alle Komponenten (Platforms, platform-tools, build-tools, NDK, CMake) statt nur für den `sdkmanager`; parallel gestartete Installationen warten aufeinander (Test: `scripts/test_codeforge_env_lock.sh`).
- **SDK / Compose-Vorschau:** `codeforge-env setup` bricht nicht mehr beim ersten Fehler ab: die übrigen Komponenten (Platforms, NDK, CMake …) werden trotzdem installiert, am Ende steht eine Liste der fehlgeschlagenen und der Exit-Code 1 (Platforms entfallen nur, wenn die cmdline-tools …
- **SDK / Compose-Vorschau:** Das vollständige SDK-Archiv (`ghsdkfull`) schreibt beim Kopieren der platform-tools die Versionsmarke `.cf-version`; ohne sie galten platform-tools als „nicht installiert“ und das mehrere hundert MB große Archiv wurde im Setup ein zweites Mal geladen.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- **Code folding** is missing (Sora Editor 0.23.4 cannot render folded regions).
- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP) are still open.
