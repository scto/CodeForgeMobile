# CodeForge Mobile 3.4.0

Android development environment on your phone: editor, terminal, Git, Gradle build, language servers, layout designer and Asset Studio – all in one app.

> ⚠️ **Pre-release / debug APK.** Signed with the Android debug key and not yet systematically tested on devices (checklist: `docs/device-test-checklist.md`). Please report bugs as issues.

## Changes since 3.3.0

### New

- **Code-Faltung:** sora-editor kommt jetzt aus dem Fork `scto/codeforgemobile-sora-editor` (0.24.7, als `third_party/sora-editor` mit Patch und Build-Skript eingebunden).
- **Terminal-Farbschemata:** Einstellungen → Terminal → Farbschema mit Vorschau (Prompt, Git-Ausgabe, 16 Farben); eingebaut „Termux-Standard“ und „CodeForge“, zehn weitere im Store (Dracula, Nord, Solarized Dark/Light, Gruvbox, One Dark, Monokai, Tokyo Night, …
- Editor: Das Kontextmenü bei Long-Click/Auswahl hat neben Alles auswählen/Kopieren/Einfügen/Ausschneiden jetzt Kommentar umschalten, Quick-Fix, Formatieren, Umbenennen, Gehe zu Definition und „Weitere Aktionen“ (Befehlspalette inkl. Plugin-Befehle); die Leiste …
- Editor-Einstellungen: Live-Vorschau unter der Theme-Auswahl – echter Editor mit Beispielcode, folgt Theme, Schrift, Schriftgröße, Zeilenabstand, Zeilennummern, Umbruch, Ligaturen und unsichtbaren Zeichen. / Live editor preview.
- Einstellungen → Debug → System-Diagnose: Gerät, Anzeige & Rendering (Bildwiederholrate, OpenGL ES, Vulkan, HDR, Farbraum), Laufzeit & Arbeitsspeicher, Speicherplatz, App- und Bibliotheksversionen; „Als Text kopieren“ für Fehlerberichte. / System diagnostics …

### Changed

- sora-editor 0.23.4 → 0.24.7 (Fork), android-tree-sitter 4.3.1 → 4.3.2; Diagnosen laufen über die Provider-API.

### Fixes

- Absturz `IndexOutOfBoundsException` in `ColorMap.getColor` nach einem Theme-Wechsel (z. B. über die Theme-Vorschau): veraltete TextMate-Farb-IDs fallen auf die Textfarbe zurück, der Editor analysiert nach dem Wechsel neu. / Crash in `ColorMap.getColor` after …

### Removed

- **Plugin-API 1 für Code-Plugins** (angekündigt in 3.3): Installation wird abgelehnt, installierte werden nicht mehr geladen und in der Plugin-Liste mit Hinweis gezeigt; `shell`/`lsp` müssen immer im Manifest stehen.

## Installation

1. Download the APK `app-debug.apk` and compare its checksum with `SHA256SUMS.txt`.
2. Install it (allow installation from unknown sources).
3. On first launch follow the onboarding: grant permissions, install the bootstrap, run the setup with `codeforge-env`.

Supported architectures: **aarch64** (main target) and **arm**.

## Known limitations

- `targetSdk = 28` is required so that Termux binaries can run – **no Play Store release possible**; distribution via GitHub/F-Droid/sideload.
- Android SDK 37 (`android-sdk-37.0.0`) is only available for aarch64.
- Device tests (bootstrap, W^X, layouts, LSP, code folding, terminal color schemes) are still open.
